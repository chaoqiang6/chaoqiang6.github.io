Redis缓存击穿如何加锁
chaoqiang.qiu
  2023-09-12 21:03:00 2023-09-12 21:03  
  • Redis 
  • | 缓存 

热点 key 过期

某个热点商品缓存刚好过期，大量请求同时发现 miss，然后一起查询数据库，这就是缓存击穿。数据库慢下来后，新的请求又会堆积。

互斥锁方案

抢不到锁的请求不能立即再打数据库，可以短暂等待后重读缓存，或者返回旧数据。

其他方式

给缓存设置随机过期时间可以降低大量 key 同时失效的概率。逻辑过期则让 value 不真正删除，由后台线程刷新，适合允许短时间读取旧数据的场景。

实际选择时

互斥锁保护的是回源过程，不是整个业务请求。允许旧数据时，逻辑过期往往比让所有请求等待更合适。
