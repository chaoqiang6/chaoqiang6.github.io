什么是缓存穿透

请求查询一个根本不存在的数据，缓存和数据库都没有结果。请求每次都会绕过缓存打到数据库，参数被人利用后，数据库连接很快就被占满。

一个简单的例子

这里的问题是不存在的数据不会写入缓存，同一个 id 会一直查询数据库。

处理方式

可以在参数层做校验，也可以缓存一个短时间的空值。对于访问量特别大的接口，还可以使用 Bloom Filter 先判断数据是否可能存在。

空值缓存需要设置较短过期时间，否则数据后来创建时会被旧的空值挡住。
