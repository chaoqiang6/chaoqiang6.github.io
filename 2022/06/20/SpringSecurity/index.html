SpringSecurity简介

安全框架

解决系统安全问题的框架，如果没有安全框架，我们需要手动处理每个资源的访问控制(创建菜单，角色，资源及相关关联表),使用安全框架，可以通过配置的方式实现对资源的访问控制

常用安全框架

  • Spring Security

    Spring Security is a framework that provides authentication, authorization, and protection against common attacks. With first class support for securing both imperative and reactive applications, it is the de-facto standard for securing Spring-based applications.

    提供身份认证，授权，防止常见攻击的框架，凭借对保护命令式和响应式应用提供一流支持，是保护基于Spring应用的事实标准

    提供了一组可以在Spring应用上下文配置的Bean，充分利用了Spring IOC,DI和AOP功能，为应用系统提供声明式的安全访问控制功能，减少了企业系统安全控制编写大量重复代码的工作

  • Apache Shiro

    功能强大且易于使用的java安全框架，提供了认证，授权，加密和会话管理
