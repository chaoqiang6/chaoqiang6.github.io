为什么想用 Spring AI

后端项目本来就是 Spring Boot 技术栈，如果为了调用大模型再单独维护一套 Python 服务，部署和权限管理都会多一层。Spring AI 提供了 ChatClient、Prompt、Tool Calling 等抽象，可以先把模型调用放进现有服务。

这里的代码很短，但线上真正需要考虑的东西并不少：API key 不能写死在配置文件里，模型响应要设置超时，错误需要脱敏记录，调用成本也要统计。

结构化输出

如果接口要返回 JSON，可以让模型映射到 Java 类型，但仍建议校验字段和枚举值。大模型的输出是外部输入，不能因为它经过模型 SDK 就跳过校验。

Spring AI 目前变化很快，具体 API 会随版本调整。学习时我会把依赖版本、模型供应商和示例代码一起记录下来，否则过几个月重新打开项目，很难判断问题来自代码还是版本升级。
