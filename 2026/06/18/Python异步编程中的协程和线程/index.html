最近重新看 Python 异步

之前写 Java 多线程时，容易把“并发”理解成创建更多线程。Python 的 async 代码不是把线程变少这么简单，它的核心是事件循环在任务等待 IO 时切换到其他任务。

await 让出执行权，但只有协程真正等待异步 IO 时才有意义。如果在协程里直接调用阻塞的 requests、文件操作或耗时计算，事件循环仍然会被卡住。

和线程的区别

线程适合复用很多同步库，协程适合大量可异步等待的网络请求。CPU 密集型任务不能只靠协程提速，通常需要进程、线程池或把任务交给专门的计算服务。

to_thread 可以把阻塞函数放到线程池，但线程池大小、超时和异常处理仍然需要配置。

我理解下来

异步代码看起来像同步代码，运行模型却完全不同。以后排查 Python 接口慢的问题，除了看数据库，也要确认有没有人在 event loop 里偷偷执行同步阻塞代码。
