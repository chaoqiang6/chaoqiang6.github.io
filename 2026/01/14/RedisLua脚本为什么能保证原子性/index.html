RedisLua脚本为什么能保证原子性
chaoqiang.qiu
  2026-01-14 23:36:00 2026-01-14 23:36  
  • Redis 
  • | Lua 

多条命令的问题

客户端先读取库存，再判断，再扣减，中间可能插入其他客户端的操作。事务可以把命令排队执行，但复杂条件判断仍然需要脚本。

Redis 执行 Lua 脚本时不会交错执行其他命令，因此脚本中的判断和修改具有原子性。

注意事项

脚本不能执行耗时循环，否则会阻塞 Redis。集群环境中脚本访问的 key 通常需要落在同一个 hash slot，跨节点 key 要使用 hash tag 设计。

结论

Lua 适合把短小的读改写逻辑放到 Redis 内部。脚本要短、可控、可监控，不能把业务系统搬进 Redis。
