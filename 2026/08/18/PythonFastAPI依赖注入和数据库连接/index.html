把连接放在哪里

写 FastAPI 接口时，数据库 session 不能在模块导入时创建一个全局对象。这样会遇到连接失效、并发共享和测试难替换等问题。

依赖函数负责创建和释放资源，请求结束后执行 finally。它和 Java 中把连接交给连接池并在 finally 或 try-with-resources 中归还，是同一种资源管理思想。

异步 session 不是自动提速

如果使用 async 数据库驱动，路由、session 和底层驱动要保持一致。同步驱动放进 async 函数里，仍然会阻塞事件循环。反过来，为了“全异步”引入复杂的库，也可能让项目维护成本增加。
