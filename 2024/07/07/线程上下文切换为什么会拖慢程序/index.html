线程上下文切换为什么会拖慢程序
chaoqiang.qiu
  2024-07-07 23:52:00 2024-07-07 23:52  
  • Java 
  • | 性能 

线程不是越多越好

线程切换需要保存寄存器、切换栈和调度下一个线程。线程数超过 CPU 承载能力后，真正执行用户代码的时间反而减少。

观察 cs 和 CPU 使用率。如果上下文切换很高但业务吞吐没有增长，通常说明并发度过大或锁竞争严重。

阻塞型任务

CPU 密集型任务的线程数通常接近 CPU 核数；IO 密集型任务可以更多，但仍然受数据库连接池、下游限流和队列长度限制。线程池大小不能脱离这些资源单独配置。

结论

性能优化要看吞吐、延迟和资源利用率。把线程数调大只是一种实验参数，不能当成通用优化方案。
